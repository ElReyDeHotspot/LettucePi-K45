# Quick Start

SIM Selection → APN Selection → WAN Port → TTL/HL → Root Password →
Timezone → Wi-Fi → Review.

Timezone uses Region → City. Wi-Fi supports shared/separate band settings
and can be disabled. Encryption choices are WPA2/WPA3, WPA2, WPA3 and Open,
with a separate choice per band when names are separate. A blank root-password field keeps the current password.
Changes apply only after the final review.

The flow uses the existing first-run access controls and closes after setup.
